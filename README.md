# ChessOpeningSmith – médiathèque marketing

Bibliothèque publique des visuels marketing de [ChessOpeningSmith](https://chessopeningsmith.com) : vidéos 9:16 (TikTok / Reels / Shorts), vidéos 4:5 (fil Instagram), carrousels, stories, images et légendes. **Aucun code, aucun secret, aucune donnée utilisateur réelle** (démos tournées avec un compte de test).

> ⚠️ Des publications Buffer programmées pointent vers des URL `raw.githubusercontent.com/Xemnai/chessopeningsmith-media/main/…` de `videos/`, `insta-4x5/` et `carousels/`. **Ne pas renommer, déplacer ni supprimer** les fichiers existants : ajouter seulement.

## Arborescence

```
videos/<fr|en>/NN-<slug>.mp4 + .srt   vidéos verticales 9:16 (1080×1920, sous-titres incrustés + .srt)
insta-4x5/<fr|en>/NN-<slug>-4x5.mp4   mêmes vidéos recadrées 4:5 (fil Instagram)
captions/<fr|en>/NN-<slug>.md         légende de publication + hashtags + texte à l’écran, par vidéo
carousels/<fr|en>/Cx-<thème>/         carrousels (6 visuels PNG)
stories/<fr|en>/                      stories 9:16 (blank/ = modèles vierges)
images/posts/<fr|en>/                 visuels uniques (posts)
images/comparison/                    comparatif Gratuit vs Premium (4:5 et story)
images/brand/                         logo et planche de marque
```
